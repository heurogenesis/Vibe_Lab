# 추가로 필요한 지시사항

현재 가정: 한국어, 비개발자·입문자, 업무 자동화/데이터 활용/교육 분야, 로컬 1인용, 비용이 드는 서비스의 실제 키는 미설정입니다. 아래는 다음 구현을 구체화하기 위한 질문입니다. 민감한 연결 정보 자체를 문서나 채팅에 쓰지 말고 선택 결과와 설정 여부만 알려주세요.

## 우선 결정할 사항

| 항목 | 필요한 답변 | 결정에 미치는 영향 | 현재 기본값 |
| --- | --- | --- | --- |
| 교육 대상 | 학생/비개발 직장인/개발자, 주요 전공·직무 2~3개, 선수 지식 | 진단 항목, 비유, 과제 예시, 난이도 | 비개발 입문자 |
| 대표 실습 | 반드시 만들 수 있어야 하는 결과물 3개와 합격 기준 | 과제 품질 평가와 프로젝트 템플릿 | 업무 보드, 지표 대시보드, 학습 카드 |
| 교육 운영 | 개인 학습/강사 운영, 총 교육 기간, 회당 시간, 예상 동시 접속 | 계정 구조, 진도 정책, 클래스 기능, 용량 | 개인, 회당 60분 |
| AI | 제공자, 사용 가능한 모델 ID, 월 예산/1인 상한, AI 외부 전송 허용 범위 | 모델 어댑터, 비용 제한, 개인정보 안내 | 키 없으면 규칙 기반 |
| 배포 | 로컬/기관 내부/공개 서비스, 원하는 호스팅과 도메인, DB 제공 방식 | HTTPS, 인증, 인프라, 백업 | 로컬 전용 |
| GitHub | 연결할 계정/조직, 공개·비공개 여부, 재사용할 템플릿 저장소 URL | OAuth/GitHub App 권한, 과제 저장소 생성 | 공개 저장소 읽기 |

## 운영 서비스를 위한 세부 결정

1. **로그인과 역할:** GitHub 로그인만 사용할지 이메일/학교 SSO도 필요한지, 학습자·강사·관리자 역할과 서로 볼 수 있는 데이터 범위를 지정해 주세요.
2. **GitHub 쓰기 자동화:** 과제별 저장소 생성, 템플릿 복제, 포크, Issue 생성, PR 제출 중 자동화할 동작을 골라 주세요. 생성 위치, 이름 규칙, 공개 범위, 실행 전 사용자 확인 여부도 필요합니다.
3. **실습 실행 환경:** 개인 편집기/Codespaces/브라우저 IDE 중 지원 범위를 알려주세요. 서버에서 학생 코드를 실행하려면 격리 실행, 시간·메모리·네트워크 제한과 별도 비용 설계가 필요합니다.
4. **평가:** 개념 퀴즈, 결과물 자동 테스트, AI 코드 리뷰, 강사 평가 각각의 비중, 합격점, 재시도, 평가 근거 공개 범위를 정해 주세요. 현재 퀴즈는 개념 확인이며 자격 인증용이 아닙니다.
5. **대화와 적응 학습:** 고정 진단 외에 튜터 대화에서 프로필을 자동 추출할지, 난이도 조절 전 동의를 받을지, 오답별 보충 자료와 장기 기억이 필요한지 알려주세요.
6. **콘텐츠:** 지정 교재/커리큘럼/공식 문서/허용 저장소 목록, 제외할 라이선스, 자료 언어, 과제 생성 검수 담당을 알려주세요.
7. **개인정보:** 수집 가능한 항목, 보관 기간, 삭제·내보내기 요구, 미성년자 포함 여부, 기관 내부 코드의 외부 AI 전송 가능 여부를 알려주세요.
8. **수업 관리:** 기수·분반, 강사 피드백, 제출 마감, 알림, 수료증, 팀 프로젝트, LMS 연동 중 필요한 기능을 알려주세요.
9. **서비스 품질:** 목표 동시 사용자, 허용 응답 시간, 백업 주기·복구 목표, 장애 알림 담당, 운영 예산을 알려주세요.
10. **브랜드와 접근성:** 서비스명, 로고, 선호 색상, 모바일 우선 여부, 한국어 외 언어와 접근성 목표를 알려주세요.

## 답변 양식

```text
교육 대상 / 주요 전공·직무:
대표 실습 3개 / 각 합격 기준:
기간 / 회당 시간 / 예상 사용자 수:
AI 제공자 / 모델 / 월 예산:
배포 환경 / PostgreSQL 준비 여부:
GitHub 조직 또는 참고 템플릿 URL / 자동화할 동작:
로그인 방법 / 역할:
그 외 필수 기능 / 제외 기능:
```

## 후속 구현 권장 순서

1. 실제 학습자 3~5명으로 진단·실습·이해도 흐름을 검증하고 대표 과제 기준을 확정합니다.
2. PostgreSQL 실연결과 선택한 AI 모델에서 과제 품질·시간·비용을 측정합니다.
3. 로그인과 사용자별 데이터 격리를 적용하고 GitHub App/OAuth로 계정 연결을 구현합니다.
4. 승인한 범위의 저장소 생성·제출 PR·Actions 평가를 자동화합니다.
5. 강사 화면, 운영 지표, 보관·삭제·백업을 갖춘 뒤 배포합니다.
