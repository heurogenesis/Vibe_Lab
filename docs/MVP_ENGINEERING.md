# 이공계 데이터 실습 MVP

## 현재 범위

로컬에서 TypeScript + React + Express + PostgreSQL(선택, 미설정 시 로컬 파일)로 개발합니다. LLM 연결보다 실행·테스트 피드백을 먼저 검증합니다. 평가 배포 단계에서만 EC2와 RDS를 사용하며, 이 변경은 AWS 리소스를 생성하지 않습니다.

- 9개 이공계 분야, 공통 분야, 프로젝트 운영 분야에 4개 데이터 처리 템플릿을 적용한 44개 실습 변형.
- 데이터 정제·평균, 그룹별 비교, 기준 충족 비율, 비동기 수집.
- 전공에 따라 데이터 의미·단위·범위·샘플·테스트가 바뀝니다. 직무·관심 테마로 순서를 추천하며 PM은 프로젝트 집계를 추가합니다.
- 브라우저 코드 셀에서 TypeScript 입력, 문법 변환, console 출력, 실행 중단, 고정 테스트와 준비된 힌트를 제공합니다.
- 전체 TypeScript 타입 검사, Python 커널, 파일 시스템, npm 설치, 운영체제 셸, 자유 형식 LLM 코드 평가 기능은 현재 제공하지 않습니다.
- 예제 코드는 프로젝트에서 작성했습니다. 참고 오픈소스의 구현을 자동 복제·실행하지 않습니다.

## 사용 방법

1. 프로젝트 루트에서 `npm.cmd run dev` 실행 후 http://127.0.0.1:5173/ 접속.
2. 학습자 프로필에서 전공·직무와 관심 테마를 저장합니다. 학습 상황에는 대학생·엔지니어 외 값을 직접 입력할 수도 있습니다.
3. **새 맞춤 과제**를 생성하면 단계별 실습에 코드 셀이 표시됩니다. 기존 과제는 보존하며 자동으로 변환하지 않습니다.
4. 또는 **데이터 실습 자료실**에서 분야·테마·검색어로 선택합니다.
5. 빈칸을 수정하고 **실행 · 테스트**를 누릅니다. 콘솔의 샘플 결과와 고정 테스트 결과는 구분됩니다.
6. **학습 기록 저장**은 테스트 요약만 저장합니다. 작성 코드는 **코드 내려받기**로 보관합니다. 편집 중인 코드는 페이지를 떠나면 유지되지 않습니다.

## 확장 구조

`shared/catalog.ts`는 분야 메타데이터, 추천 규칙, 교육 계약과 테스트를 관리합니다. `personaId`, `disciplineId`, `interests`는 선택적 문자열/문자열 배열이므로 신규 ID 추가에 DB enum 변경이 필요하지 않습니다. 기존 프로필도 읽을 수 있습니다. 알 수 없는 전공은 공통 과제로 연결하고 추천 이유에 표시합니다.

새 분야는 단위·범위·관측 그룹을 등록하고 기존 알고리즘을 재사용할 수 있습니다. 새 알고리즘은 실습 생성기와 참조 테스트를 함께 추가합니다. 단순히 전공 이름을 바꾸는 것과 새로운 전문 이론을 검수하여 추가하는 것은 다릅니다. 현재는 공통 데이터 처리 학습이며 산업 설계·안전 규격을 판정하지 않습니다.

과제에는 `catalogVersion`과 실습 ID만 추가 저장합니다. 버전이 다르면 현재 코드를 잘못 연결하지 않고 새 과제 생성을 안내합니다. 콘텐츠 개정 시 버전을 갱신해야 하며, 장기 운영 단계에는 이전 버전 아카이브 조회가 필요합니다.

## 외부 데이터와 저장 비용

`shared/data-sources.ts`의 등록된 원본을 `src/data-loader.ts`가 브라우저에서 직접 읽습니다. 기본 합성 데이터는 브라우저에서 생성합니다.

- 실제 GitHub 연결: Palmer Penguins (체질량, 종). Vega Datasets의 커밋 `2434f551e0bb12b99a4ce6764fbc0ef39bea145e`에 고정.
- [원본과 인용](https://allisonhorst.github.io/palmerpenguins/) · 데이터 CC0-1.0.
- [배포 JSON](https://github.com/vega/vega-datasets/blob/2434f551e0bb12b99a4ce6764fbc0ef39bea145e/data/penguins.json).
- 생명·바이오 실습에서 공개 원본을 선택할 수 있습니다. 다른 분야는 현재 합성 데이터이며 실제 산업 데이터를 연동했다고 표시하지 않습니다.
- HTTPS, 쿠키 제외, 리다이렉트 거부, 10초 타임아웃, 스트리밍 크기 제한, 행 수·필드 검증을 적용합니다.
- 원자료는 서버/DB에 업로드하지 않습니다. 브라우저 메모리 캐시는 최대 8개, 15분이며 새로고침하면 사라집니다.
- 실패를 샘플 성공으로 숨기지 않습니다. 오류를 표시하고 사용자가 샘플로 전환합니다.
- 일반 `http-json` 공급자 메타데이터도 등록할 수 있습니다. 실제 외부 DB 연결은 아직 없으며, DB 자격 증명 대신 읽기 전용 HTTPS API와 CORS/조회 제한을 갖춘 공급자를 추가해야 합니다. 비공개 키가 필요한 공급자는 추후 서버 어댑터로 분리합니다.

서버에는 프로필·과제·기존 진도와 최근 100건의 실행 요약을 보관합니다. 각 과제에는 실습별 마지막 결과만 남깁니다. 결과 API는 코드·원자료 같은 추가 필드를 거부합니다. 전체 과제/대화 저장 방식은 기존 단일 로컬 JSONB 워크스페이스를 유지합니다. 여러 사용자에게 공개하기 전 사용자별 접근 제어와 저장 모델 분리가 필요합니다.

GitHub는 변경 가능한 학습 원본 배포처로 사용하며 학습 진도·사용자 정보의 DB로 사용하지 않습니다. 외부 API/DB도 요청량·전송량·이용 조건에 따른 비용이 있을 수 있습니다.

## 실행과 피드백의 경계

사용자 코드는 서버에서 실행하지 않습니다. TypeScript를 브라우저에서 JavaScript로 변환한 뒤 opaque-origin iframe 내부의 전용 Worker에서 실행합니다. iframe은 `allow-scripts`만 허용하고 네트워크·폼·하위 프레임을 CSP로 차단합니다. 상위 페이지의 CSP는 eval을 허용하지 않습니다. 실행마다 새 프레임을 만들고 5초 제한·중지·편집·화면 이탈 시 폐기합니다. 메시지 출처·실행 ID·결과 형식도 확인합니다.

이는 로컬 연습 환경입니다. 브라우저가 보고한 테스트 결과는 조작 가능한 자기 학습 기록이며 공인 시험 점수로 사용하지 않습니다. 고의적인 자원 고갈에 대한 완전한 메모리 격리도 보장하지 않습니다. 다중 사용자 서버 터미널을 제공하려면 별도 컨테이너/VM 격리, 자원 제한, 수명 관리가 필요합니다.

실시간 LLM 튜터는 별도 단계입니다. 제공받은 키는 선결제된 API 사용 계정의 키이며 LG Display 전용 API라고 가정하지 않습니다. 실제 공급자·모델·엔드포인트 확인 후 서버 환경변수로 연결합니다. OpenAI 호환이라는 표현만으로 Responses API/구조화 출력까지 지원한다고 가정하지 않습니다. 새 실행 실습의 생성과 테스트에는 모델 호출이 없습니다.

## 평가 배포 비용과 포트폴리오

2026-09-12 조회한 서울 리전 공개 온디맨드 가격을 바탕으로 한 개략치입니다. AWS 크레딧을 차감하지 않았고 달러당 1,500원을 가정했습니다.

가정: Linux EC2 t3.small 1대, RDS PostgreSQL db.t4g.micro Single-AZ 1대, 각 20GB gp3, 공인 IPv4 1개, 소량 트래픽과 로그. 참고 단가는 EC2 $0.026/시간, RDS $0.025/시간, EBS $0.0912/GB-월, RDS 저장공간 $0.131/GB-월, IPv4 $0.005/시간입니다. 730시간 기준 기본 합계는 약 $45이며 로그·변동 비용을 고려해 여유를 둡니다.

| 사용 기간 | 예산 범위 |
|---|---:|
| 로컬 개발 | AWS 0원 |
| 평가 2~3일 | 약 1만~2만 원 |
| 평가 1주 | 약 2만~3만 원 |
| 상시 1개월 | 약 7만~10만 원 |

실사용·세금·환율·리소스 보관 기간에 따라 달라집니다. LLM 토큰, 도메인, 별도 ALB/NAT Gateway, Multi-AZ 구성은 포함하지 않았습니다. 계산은 평가 종료 후 리소스를 삭제하는 조건이며, 단순 중지는 디스크·스냅샷 비용을 없애지 않습니다. RDS는 일시 중지 후 7일이 지나면 자동 시작하므로 장기 방치하지 않습니다.

- [EC2 요금](https://aws.amazon.com/ec2/pricing/on-demand/), [서울 EC2 공식 가격표 CSV](https://pricing.us-east-1.amazonaws.com/offers/v1.0/aws/AmazonEC2/current/ap-northeast-2/index.csv)
- [RDS 요금](https://aws.amazon.com/rds/postgresql/pricing/), [서울 RDS 공식 가격표 CSV](https://pricing.us-east-1.amazonaws.com/offers/v1.0/aws/AmazonRDS/current/ap-northeast-2/index.csv)
- [IPv4 요금](https://aws.amazon.com/vpc/pricing/), [RDS 일시 중지](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_StopInstance.html)

클라우드 포트폴리오는 서비스 배포에 더해 IaC 재현, GitHub Actions 배포/롤백, 비공개 RDS와 최소 권한, HTTPS·비밀 관리, 로그·알람, 백업 복구 실험, 비용 비교, 평가 후 리소스 정리 증거를 남기면 설득력이 높습니다. 로컬 MVP 검증 후 이 순서로 평가 배포를 준비합니다. 현재 로컬 전용 Host/Origin 제한은 유지하며, 공개 배포 전 인증·사용자 분리·배포용 허용 목록·RDS TLS를 먼저 구성해야 합니다.
