# 개인화 학습자료 생성(Brave Search + 생성형 AI) 검토·실행 계획

> 작성: Claude Code, 2026-09-12. 근거: `PROGRESS.md`/`ROADMAP.md` 현재 상태와 `server/ai.ts`·`shared/catalog.ts`·`shared/data-sources.ts` 실제 코드 확인, Brave/OpenAI/Anthropic/OpenAI(ChatGPT)/Anthropic(Claude) 공식 요금 페이지 확인(2026-09-12 기준, 하단 출처 참고).
> 이 문서는 `AGENTS.md`의 우선순위(AGENTS → PROGRESS → ROADMAP → git 상태)와 충돌하지 않도록, 기존 문서에 없는 **새 트랙**만 별도 파일로 관리합니다. 진행 상태 갱신은 계속 `PROGRESS.md`에서, 일정·의존성은 `ROADMAP.md`에서 관리하되, 이 기능의 세부 설계·비용·일정은 여기서 관리합니다.

## 0. 먼저 구분해야 할 두 가지 문제

**문제 A (기존 라우팅 이슈로 추정, 이미 추적 중인 항목):** "프로필을 바꿔도 실습 워크스페이스가 안 바뀐다"는 증상은 새 버그가 아니라 이미 `ROADMAP.md`의 P0-05("기존 이공계 프로필이 관심 분야를 저장했어도 새 실습으로 연결되는 경로 확인")로 추적 중인 항목과 같은 증상일 가능성이 높습니다. 코드를 확인해보니 `shared/catalog.ts`의 `usesPractice(profile)`가 `domain === 'data'`이거나 `personaId`가 있거나 전공이 `general`이 아니면 **항상** 결정론적 44개 실습 카탈로그(`generateRules`)로 보내고 `server/ai.ts`의 생성형 AI 경로는 건너뜁니다. 즉 프로필이 조금이라도 채워져 있으면 지금 구조상 AI 개인화 경로 자체가 거의 호출되지 않으며, 44개 실습도 "9개 전공 × 4개 공통 템플릿"의 굵은 단위라 프로필 조합이 달라도 같은 실습으로 보일 수 있습니다. 이건 1~2개 파일 수준의 원인 확인·수정 작업입니다.

**문제 B (이번에 요청하신 새 기능):** 프로필 조합별로 Brave Search로 자료를 조사하고, 생성형 AI가 그 조사 결과를 반영해 실제로 다른 학습자료를 만들어내는 것. 이는 `usesPractice()` 게이트 자체를 다시 설계해야 하는, `ROADMAP.md`의 P1-02(LLM 피드백)보다 범위가 큰 새 트랙입니다.

이 문서는 문제 B를 중심으로 다루되, 문제 A를 먼저 짧게 확인·정리하고 시작할 것을 제안합니다. 문제 A가 방치된 채 문제 B를 쌓으면, 개인화가 "제대로 됐는지" 자체를 판단하기 어려워집니다.

## 1. 범위와 가정

- **가정 1 (LLM 공급자):** `server/ai.ts`는 이미 OpenAI SDK(`openai` 패키지, Responses API)를 사용 중입니다. `AGENTS.md`는 "제공받는 키는 선결제 API 사용 계정의 키이며 실제 공급자는 미확인"이라고 명시합니다. 비용은 OpenAI 계열 소형 모델(2026-09 기준 GPT-5.6 Luna, 입력 $0.20 / 출력 $1.20 per 1M 토큰)을 기준으로 계산하고, Anthropic Claude Haiku 4.5(입력 $1 / 출력 $5 per 1M 토큰)를 대안으로 병기합니다. **실제 키의 공급자·모델이 확정되면 이 추정치는 다시 계산해야 합니다.**
- **가정 2 (검증 규모):** "MVP 단계 기능 검증 + 포트폴리오 제작"으로 범위를 한정합니다 — 실사용자 다수가 아니라 대표 프로필 조합 15~20개를 반복 실험하는 수준입니다. 실서비스 규모 비용은 5절 맨 아래에 참고용으로만 남깁니다.
- **가정 3 (검색 API):** Brave Search Search Plan 기준 — $5 / 1,000건, 월 $5 무료 크레딧 포함(≈월 1,000건 무료).
- **범위 밖:** 사용자 인증, 다중 사용자 동시성 처리, AWS 상시 운영. AWS는 `ROADMAP.md` 7절의 "평가 배포"용 개략 예산을 그대로 재사용합니다.

핵심 결론: 이 규모(검증 + 포트폴리오)에서는 Brave Search·GenAI API의 실제 변동비가 **사실상 오차 범위 수준(5만원 이내)**입니다. 이미 지불 중인 Claude Pro/ChatGPT Plus 구독료가 사실상 전체 비용의 대부분을 차지합니다.

**참고 (범위 밖, 실서비스 확장 시):** 사용자 1,000명이 각 1회씩 개인화 자료를 받는다고 가정하면 Brave Search만 약 $5~15, GenAI 생성은 모델에 따라 $50~500대까지 벌어질 수 있어 실서비스 전환 시 별도 예산 검토가 필요합니다. 이번 계획의 범위는 아닙니다.

## 5. 남은 리스크 및 사용자 결정 필요 사항

1. 실제 LLM 공급자·모델이 아직 미확정(`AGENTS.md` 기존 항목) — 이 계획의 비용 추정 정확도에 직접 영향을 줍니다. 공급자가 확정되면 3절 표를 다시 계산해야 합니다.
2. `usesPractice()` 게이트를 개인화가 "보완"할지 "대체"할지 결정이 필요합니다(PZ-01에서 다룸).
3. Brave Search 실제 계정·키 발급이 필요합니다(현재 미보유로 가정).
4. GPT Plus/Claude Pro 세션 소진 속도는 공식 수치가 없어 추정치이며, 실사용 후 조정이 필요합니다.
5. 문제 A(P0-05)가 예상보다 큰 원인(예: 카탈로그 설계 자체의 한계)으로 밝혀지면 문제 B의 일정에도 영향을 줄 수 있습니다.
